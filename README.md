# Cinema Management Database – SQL Project

## Project Overview

This project focuses on designing and implementing a relational database for a cinema management system.

The database was created from scratch and is designed to store and manage information about movies, genres, cinemas, screening rooms, screenings, customers, tickets, payments and employees.

The main goal was to create a structured database that allows information to be stored, connected and analyzed using SQL queries.

## Database Structure

The database consists of 11 related tables:

- FILM – information about movies
- GATUNEK – movie genres
- KINO – cinemas
- KLIENT – customers
- KONTO – customer accounts
- SALA – screening rooms
- SEANS – movie screenings
- FILM_GATUNEK – relationship between movies and genres
- BILET – tickets
- PLATNOSC – payments
- PRACOWNIK – employees

The tables are connected using primary and foreign keys.

A many-to-many relationship between movies and genres was implemented using the `FILM_GATUNEK` associative table.

## What Was Done

The database was created from scratch, starting with the database structure and relationships between the entities.

The project included:

- designing the database structure
- creating tables
- defining primary and foreign keys
- creating relationships between tables
- inserting data into the tables
- creating sequences for generating unique IDs
- writing SQL queries for different business cases
- creating views to simplify access to frequently used data
- performing basic analytical queries

## SQL Analysis

Several queries were created to work with and analyze the data.

The database allows us to:

- find movie screening schedules
- find customers who purchased tickets for a specific movie
- rank movies by the number of sold tickets
- calculate total revenue generated by movies
- filter movies by genre
- calculate monthly revenue for individual cinemas
- analyze customers and their account status
- find screenings with prices above the average
- calculate average revenue per movie
- find movies with revenue above the average

## Views

Several views were created to make working with the database easier:

- `V_SEANSY` – screening information with cinema and movie names
- `V_BILETY` – information about sold tickets, customers and payments
- `V_PRZYCHODY_FILM` – revenue generated by each movie
- `V_KLIENCI_KONTA` – customers and their account status
- `V_DROGIE_SEANSE` – screenings with prices above the average

## Database Design

The database was designed to represent the main processes of a cinema.

For example, a movie can have one or more genres, a cinema can contain several screening rooms, and each screening connects a movie with a specific room and date.

Customers can purchase tickets for screenings, while payments are connected to the purchased tickets.

This structure makes it possible to combine information from different parts of the database and perform more complex SQL analysis.

## Result

The final result is a complete relational database that can be used to manage cinema-related information and perform analytical queries.

The project covers the process from designing the database structure and creating tables to inserting data, connecting entities and analyzing the stored information using SQL.
